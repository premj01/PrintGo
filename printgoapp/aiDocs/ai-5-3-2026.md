### 2. Global Auth State via `useContext`

| What | Details |
|---|---|
| **Context** | `AuthContext` in `contexts/auth/AuthContext.tsx` |
| **Provider** | `AuthProvider` wraps entire app in `main.tsx` |
| **Hook** | `useAuth()` — typed access with safety throw |
| **State** | `user`, `token`, `isAuthenticated`, `isLoading` |
| **Actions** | `login(code)`, `logout()`, `setUser(user)` |
| **Persistence** | localStorage hydration on mount, auto-clear on 401 |

**OAuth Flow:**
1. User clicks "Sign In" → redirects to Google OAuth
2. Google redirects back to `/oauth-callback?code=...`
3. `OAuthCallbackPage` calls `useAuth().login(code)`
4. `AuthProvider` sends code to server (`POST /auth/google`)
5. Server exchanges code for Google token → returns app JWT + user
6. `AuthProvider` stores in localStorage + updates context state

**Not all routes need auth:**
- `/upload`, `/kioskRedirect` work WITHOUT authentication (kiosk QR flow)

### 3. Dark/Light Theme System

| What | Details |
|---|---|
| **Context** | `ThemeContext` in `contexts/theme/ThemeContext.tsx` |
| **Provider** | `ThemeProvider` wraps app (outermost in `main.tsx`) |
| **Hook** | `useTheme()` — `theme`, `toggleTheme()`, `isDark` |
| **Mechanism** | Toggles `.dark` class on `<html>` element |
| **CSS** | `:root` defines light colors, `.dark` overrides with dark colors |
| **Persistence** | Saved to `localStorage` key `printgo_theme` |
| **System detect** | Falls back to `prefers-color-scheme: dark` if no saved pref |
| **Toggle UI** | Sun/Moon button in Navbar (desktop + mobile) |

**Color configuration — single source of truth:**
- **`config/colors.ts`** — all light/dark palette values defined here
- **`styles/globals.css`** — `:root` and `.dark` CSS custom properties
- To try different colors, edit these two files only

**Dark palette choice:** GitHub-style dark (#0d1117 background, #161b22 cards, #e6edf3 text) with adjusted PrintGo greens.

### 6. HomePage Redesign

Redesigned from basic text-heavy layout to a **visual step-by-step flow**:

**Hero Section:**
- "Scan. Upload. Print." headline with gradient text
- Badge, stats row (< 2 min, ₹2/pg, 0 apps required)
- CTA buttons + scroll hint

**How It Works — 6-Step Vertical Flow:**
1. 📱 Scan QR — scan code on kiosk with phone camera
2. 📄 Upload Files — PDF, images, documents
3. 📋 Select Pages — pick which pages to print
4. 🎨 Pick Options — color/B&W, duplex, copies
5. 💳 Pay — UPI, card, wallet
6. ✅ Collect Print — prints come out automatically

Each step is a **card** with icon + number badge + description + emoji, connected by **arrows** in a straight vertical line. Celebration message at the end.

**Compact Flow Strip:**
- Desktop: horizontal pill row with arrows
- Mobile: 2-column numbered grid (mobile-optimized)

**Why PrintGo:** 4-card grid (No Queues, Under 2 Min, No App, 100% Private)

**CTA:** Green banner with "Ready to Print?"

2. Edit **`src/styles/globals.css`** — update `:root` and `.dark` hex values
3. That's it — entire app theme updates
